# Toolkit artwork

These local copies retain the supplied capability atlas’s logo mappings. They are served locally so the atlas does not depend on a third-party image CDN.

- 29 SVGs from [Devicon](https://github.com/devicons/devicon), `icons/` directory. MIT license: `DEVICON-LICENSE`.
- Hugging Face, LangChain and WebGL: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons). These three slugs were absent from Devicon. CC0 dedication: `SIMPLE-ICONS-LICENSE`. Their fill is adapted for the atlas’s light badges; geometry is unchanged.
- Product names without a distinct supplied logo retain the original atlas’s monogram fallback.

Prepared on 2026-10-09 with `scripts/adapt-skill-atlas.py --fetch-logos`. Collected source HTML remains unchanged.
